# Experiment Intelligence Dashboard

A professional Streamlit dashboard that analyzes A/B testing experiments using real-world conversion data.

---

## Features

- Executive Dashboard
- A/B Test Analysis
- Segmentation Dashboard
- Data Quality Monitoring
- Event Explorer
- Metric Dictionary
- Decision Center
- SQLite Database
- Statistical Significance Testing
- CSV Export

---

## Dataset

ecommerce_conversion_ab_test_data.csv

Contains

- Variant
- Conversion
- Device
- Traffic Source
- Browser Language
- Login Status
- Returning User
- Region
- Date

---

## Installation

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
